# نُوا — شبکه اجتماعی فارسی

این پروژه یک نمونه اولیه قابل اجرا از شبکه اجتماعی با رنگ‌های بنفش، صورتی، مشکی و قرمز است.

## امکانات
- ثبت‌نام و ورود با رمز عبور هش‌شده
- نشست ورود با کوکی
- انتشار پست متنی و عکس
- لایک و دیدگاه
- جست‌وجو و دنبال کردن کاربران
- پروفایل و ویرایش معرفی کوتاه
- پیام خصوصی متنی
- پایگاه داده SQLite
- رابط واکنش‌گرا برای موبایل و دسکتاپ

## پیش‌نیاز
Node.js نسخه 18 یا جدیدتر و npm.

## اجرا در ویندوز، مک یا لینوکس
1. فایل ZIP را از حالت فشرده خارج کن.
2. ترمینال یا Command Prompt را در پوشه پروژه باز کن.
3. اجرا کن:
   ```bash
   npm install
   npm start
   ```
4. در مرورگر باز کن:
   `http://localhost:3000`

## اجرا روی گوشی
برای تست روی گوشی، گوشی و کامپیوتر باید به یک شبکه Wi-Fi متصل باشند. در کامپیوتر آدرس IP محلی آن را پیدا کن و در گوشی باز کن، مانند `http://192.168.1.20:3000`. عدد IP در هر شبکه متفاوت است. ممکن است لازم باشد اجازه دسترسی برنامه Node.js را در فایروال بدهی.

## محل ذخیره‌سازی
- پایگاه داده: `nova.sqlite` (به‌صورت خودکار ساخته می‌شود)
- عکس‌های بارگذاری‌شده: پوشه `uploads`

## نکات مهم پیش از انتشار عمومی
این پروژه نمونه آموزشی/اولیه است، نه نسخه آماده برای سرویس عمومی. پیش از انتشار:
- مقدار `SESSION_SECRET` را با یک مقدار تصادفی و محرمانه تنظیم کن.
- از ذخیره‌ساز نشست پایدار (مانند SQLite/Redis session store) استفاده کن؛ ذخیره‌ساز پیش‌فرض نشست Express فقط برای نمونه محلی است.
- HTTPS، محدودسازی نرخ درخواست‌ها، محافظت CSRF متناسب با معماری، اعتبارسنجی دقیق فایل‌ها و اسکن تصاویر را اضافه کن.
- برای فایل‌های بارگذاری‌شده سقف و سیاست نگهداری تعریف کن و پشتیبان‌گیری منظم از SQLite داشته باش.
- سیاست حریم خصوصی، گزارش محتوا، مسدودسازی کاربر، بازیابی رمز و مدیریت سوءاستفاده را پیاده‌سازی کن.
- برای پیام‌های زنده می‌توان WebSocket اضافه کرد؛ نسخه فعلی پیام‌ها را از طریق API می‌فرستد و با تازه‌سازی صفحه/بازکردن گفتگو دریافت می‌کند.
- اگر روی میزبان عمومی اجرا می‌کنی، تنظیمات کوکی امن و متغیر `NODE_ENV=production` را فقط همراه HTTPS فعال کن.

## توجه
این پروژه برای اجرای محلی است. برای اینکه افراد از هر جای دنیا به سایت دسترسی داشته باشند، باید آن را روی یک سرور یا پلتفرم میزبانی منتشر کنی و دامنه/HTTPS تنظیم شود.


## تنظیم مسیر داده برای میزبانی
برنامه از متغیر `DATA_DIR` پشتیبانی می‌کند. در سرویس میزبانی، یک فضای ذخیره‌سازی پایدار بساز و مسیر اتصال آن را در `DATA_DIR` قرار بده؛ مثلاً در Railway اگر Volume روی `/data` متصل شده، مقدار `DATA_DIR=/data` را تنظیم کن. پایگاه داده و عکس‌های کاربران در آن مسیر ذخیره می‌شوند. بدون دیسک/Volume پایدار، داده‌ها ممکن است با استقرار مجدد از بین بروند.
